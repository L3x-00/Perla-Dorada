# Arquitectura inicial

- Next.js App Router y TypeScript.
- Componentes de servidor por defecto.
- Acceso a datos desde código de servidor para operaciones críticas.
- Supabase para PostgreSQL, Auth, Storage y Realtime.
- Validación de entradas con Zod.
- Organización modular por funcionalidades.
- Base de datos como fuente de verdad.
- Operaciones críticas mediante transacciones.
